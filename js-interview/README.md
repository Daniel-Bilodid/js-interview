# 🧠 Interview Prep — мій сайт для підготовки до співбесід

Особистий довідник з питаннями та відповідями по
**JavaScript / TypeScript / React / React Native / Архітектура**.
Кожна тема — це: пояснення простими словами → приклади коду → підводні камені.

## Як запустити

```bash
npm install   # один раз
npm run dev   # відкрити http://localhost:5173
```

## Як користуватись

- Обирайте тему в списку ліворуч або гортайте стрілками **← →** на клавіатурі.
- Кнопка **«Позначити вивченим»** (або чекбокс у списку) зберігає прогрес — він
  запам'ятовується в браузері (localStorage) і нікуди не зникне.
- Пошук угорі списку шукає по назвах і текстах тем.
- 🌙/☀️ — перемикач темної/світлої теми.

## Глибина розкриття теми

Угорі кожної теми є перемикач **Глибина** — він визначає, скільки з теми показати.
Вибір спільний для всього сайту і памʼятається між сесіями.

| Режим | Коли брати | Що показує |
|---|---|---|
| 🔁 Повторення | тему знаю, треба освіжити | 🎯 визначення + 🎖 senior-нюанси |
| 📖 Розібратись | тему знаю погано | + 💡 простими словами + 💻 приклади |
| 🌱 З нуля | бачу вперше | + ❓ навіщо це існує + 🔗 супутні теми |

Той самий перемикач є на стартовому екрані 🎯 Самоперевірки — він керує тим,
скільки відкривається при показі відповіді.

## Як додати нове питання

Найшвидше — командою в Claude Code:

```
/add-topic Як працює React Navigation
/add-topic ts Що таке variance у TypeScript
/add-topic rn Deep linking; Push-сповіщення
```

Скіл сам обере файл, напише тему в розгорнутому форматі, зареєструє її в
масиві порядку і прожене валідатор. Він лежить у `.claude/skills/add-topic/`.

Перевірити формат усіх тем вручну:

```bash
npm run check:topics              # усі теми
npm run check:topics -- rn-lists  # конкретну
```

Валідатор перевіряє унікальність id, обсяг кожного поля, наявність id у
`*_ORDER` і ловить текстові штампи. Теми старого формату він перевіряє лише
на унікальність id.

### Руками


Відкрийте потрібний файл у `src/data/` і скопіюйте шаблон із коментаря вгорі
файлу в кінець масиву (перед закривною `]`).

**Розгорнутий формат** (React Native і всі нові теми):

```ts
{
  id: 'rn-unikalnyi-id',
  title: 'Питання, як його ставить інтервʼюер',

  // 🎯 показується ЗАВЖДИ, навіть у режимі «Повторення»
  definition:
    'Ідеальне визначення, яке мав би дати senior. 2-4 речення, готові до озвучення.',

  // ❓ тільки в режимі «З нуля»
  why: 'Навіщо це існує і яку проблему вирішує.',

  // 💡 у режимах «Розібратись» і «З нуля»
  simple: 'Пояснення простими словами — глибоко, але без складних слів.',

  // 🔗 тільки в режимі «З нуля»
  related: [
    { title: 'Супутня тема', text: 'Без чого основна тема не розкривається.' },
  ],

  // 💻 у режимах «Розібратись» і «З нуля»
  codeExamples: [
    { label: 'Що показує приклад', code: `const x = 1;` },
  ],

  // 🎖 показується ЗАВЖДИ
  seniorNotes: ['Нюанс, який відрізняє senior від middle.'],
},
```

**Короткий формат** — ним написані наявні теми JS / TS / React / Архітектура.
Він і далі працює: `description` підставляється замість `simple`, а `gotchas` —
замість `seniorNotes`.

```ts
{
  id: 'unikalnyi-id',
  title: 'Питання',
  description: 'Пояснення простими словами.',
  codeExamples: [{ label: 'Приклад', code: `const x = 1;` }],
  gotchas: ['Підводний камінь.'],
},
```

Обидва формати можна змішувати в одному файлі — поля опційні.

Збережіть файл — сторінка оновиться сама (HMR), тема зʼявиться **в кінці**
списку. Щоб поставити її на своє місце за складністю, впишіть її `id` у
потрібне місце масиву `*_ORDER` у `src/data/index.ts`.

Три граблі:

1. `id` має бути унікальним **глобально**, а не лише у файлі — прогрес
   зберігається в одному спільному наборі id.
2. Не називайте тему `id: 'practice'` — це зарезервований роут самоперевірки.
3. Код у `codeExamples` лежить у backtick-рядку: екрануйте зворотні лапки
   та `${` усередині.

## Як додати нову технологію (вкладку)

1. `src/types.ts` → додати ключ у `TabKey`
2. новий файл `src/data/<назва>.ts` з `export const <назва>Topics: Topic[]`
3. `src/data/index.ts` → імпорт, за бажанням масив `*_ORDER`, рядок у `tabs`
4. `src/components/RichText.tsx` → дописати терміни технології в `KEYWORDS`,
   щоб вони підсвічувались у тексті

Вкладка, роутинг, сайдбар, прогрес і самоперевірка підхопляться автоматично.

## Структура проєкту

```
src/
  data/          ← ПИТАННЯ ЖИВУТЬ ТУТ (javascript.ts, react.ts, reactnative.ts…)
    index.ts     ← складання вкладок і порядок тем (*_ORDER)
  components/    ← сторінка теми, список, самоперевірка, перемикач глибини
  hooks/         ← збереження прогресу, глибини і теми оформлення
  utils/topic.ts ← що показувати на кожному рівні глибини
  types.ts       ← формат теми (Topic) і рівні глибини (Depth)
```
