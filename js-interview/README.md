# 🧠 Interview Prep — мій сайт для підготовки до співбесід

Особистий довідник з питаннями та відповідями по **JavaScript / TypeScript / React**.
Кожна тема — це: пояснення простими словами → приклади коду → підводні камені.

## Як запустити

```bash
npm install   # один раз
npm run dev   # відкрити http://localhost:5173
```

## Як користуватись

- Обирайте тему в списку ліворуч або гортайте стрілками **← →** на клавіатурі.
- Кнопка **«Позначити вивченим»** (або чекбокс у списку) зберігає прогрес — він
  запам'ятовується в браузері (localStorage) і нікуди не зникне.
- Пошук угорі списку шукає по назвах і текстах тем.
- 🌙/☀️ — перемикач темної/світлої теми.

## Як додати нове питання

1. Відкрийте потрібний файл:
   - `src/data/javascript.ts`
   - `src/data/typescript.ts`
   - `src/data/react.ts`
2. Угорі кожного файлу є готовий шаблон у коментарі — скопіюйте його
   в кінець масиву (перед закривною `]`) і заповніть:

```ts
{
  id: 'unikalnyi-id', // латиницею, через дефіс, унікальний
  title: 'Питання, як його ставлять на співбесіді',
  description:
    'Пояснення простими словами. Пишіть кількома реченнями — сайт сам розіб\'є текст на абзаци, а назви функцій і код у тексті підсвітить автоматично.',
  codeExamples: [
    {
      label: 'Що показує приклад',
      code: `const x = 1; // сам код`,
    },
  ],
  gotchas: [
    'Підводний камінь або каверзне запитання №1.',
    'Підводний камінь №2.',
  ],
},
```

3. Збережіть файл — сторінка оновиться сама (HMR), тема з'явиться внизу списку.

## Структура проєкту

```
src/
  data/          ← ПИТАННЯ ЖИВУТЬ ТУТ (javascript.ts, typescript.ts, react.ts)
  components/    ← вигляд сторінки теми, список, блоки коду
  hooks/         ← збереження прогресу і теми оформлення
  types.ts       ← формат теми (Topic)
```
